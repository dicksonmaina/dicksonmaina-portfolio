## Philosophy

1. **Code is information** — the system can upgrade itself if it can read and write code
2. **No crash is acceptable** — circuit breakers, pre-flight checks, and auto-revert are non-negotiable
3. **Learning is mandatory** — every bug, fix, and pattern must be stored and reused
4. **Free and open** — build with free models, open tools, and zero vendor lock-in
5. **Speed matters** — lightweight models, fast responses, no bloat
